# GitHub Copilot Instructions

Use `AGENTS.md` as the repository guide.

Suggestions should favor sanitized templates, consistent terminology, and safe public documentation. Avoid adding private project state, secrets, generated context bundles, or exploit-specific security wording.

Follow the Ponytail Decision Ladder from `rules/PONYTAIL_LAZY_DEV_PROTOCOL.md`: prefer YAGNI, stdlib, native features, and minimal code over new abstractions or dependencies.
