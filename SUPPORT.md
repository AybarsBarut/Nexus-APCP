# Support

Nexus-APCP is an open-source protocol kit. The fastest way to get useful help is to choose the right channel and include sanitized context.

## Where to Ask | Need | Best place |
| :--- | :--- |
| Broken command, bad link, or incorrect instruction | GitHub issue using the bug report template |
| Missing setup detail or confusing documentation | GitHub issue using the documentation template |
| New protocol workflow, prompt, or example kit | GitHub issue using the protocol suggestion template |
| Security-sensitive concern | Private vulnerability reporting, if available |
| Private project adaptation | Keep details local and use sanitized examples in public | ## What to Include

- The file or section you are using.
- The command you ran, if any.
- The AI tool or workflow involved, if relevant.
- What you expected to happen.
- What happened instead.

## What Not to Include

- Secrets, tokens, credentials, `.env` values, or service-account files.
- Filled private project context.
- Customer data, logs, exports, or internal architecture maps.
- Generated `PROMPT_READY.txt` from private repositories.
- Exploit details or vulnerability reproduction steps.

## Response Expectations

This project is maintained as time allows. Clear, small, sanitized reports are easier to review and more likely to be addressed quickly.
