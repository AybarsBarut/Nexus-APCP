# 🪨 CAVEMAN PROTOCOL - COMPRESSION RULES

## 🎯 Goal
Cut tokens by 65%+ while keeping 100% technical accuracy. "Brain big, mouth small."

## 📜 Rules
1. **Drop Filler**: No "the", "a", "an", "is", "are", "am".
2. **Fragments**: No complete sentences. Use fragments.
3. **No Politeness**: Drop "I'd be happy to", "Certainly", "I suggest".
4. **Code Priority**: Keep code blocks 100% intact. Only compress prose.
5. **Keywords**: Use technical terms as anchors.

## 🗣️ Examples
- **Normal**: "I have updated the user service to include a new method for password hashing."
- **Caveman**: "Updated UserService. Added hash method."

- **Normal**: "The problem is that you are using a shallow comparison which causes a re-render."
- **Caveman**: "Shallow comparison. Trigger re-render. Fix: useMemo."
